## Amendment A — conversation-envelope JSONL

Task 3's `JsonRecordsAdapter` must additionally accept normalized conversation envelopes of the form:

```json
{
  "messages": [
    {"role":"user","content":"...","timestamp":"2026-01-16T14:30:22Z"},
    {"role":"assistant","content":"...","timestamp":"2026-01-16T14:30:25Z"}
  ],
  "source":"cursor-composer",
  "session_id":"c1a2b3",
  "project_path":"/work/project",
  "created_at":1705414222000
}
```

Each nested message becomes one `EvidenceEvent`. Identity priority is:

1. explicit message `record_id` / `id` / `message_id`;
2. otherwise deterministic `{source}:{session_id}:{message_index}`.

The event source locator records file path + line number + message index. Session/project/model/tool metadata is retained in `metadata`. Message timestamp outranks envelope `created_at`; the envelope time is fallback only. Extraction confidence/heuristic flags, if present, are retained and never upgraded to stronger epistemic status by Roots.

Add tests:

```python
def test_conversation_envelope_yields_message_events():
    events = list(adapter.discover(target))
    assert [e.metadata["message_index"] for e in events] == [0, 1]
    assert events[0].record_id.endswith(":0")


def test_message_timestamp_beats_conversation_created_at():
    assert events[0].event_time.start.isoformat().startswith("2026-01-16T14:30:22")
```

```python
def test_git_history_adapter_emits_history_as_evidence_not_log_order(tmp_path):
    repo, file_path = build_three_commit_repo(tmp_path)
    adapter = GitFileHistoryAdapter(repo, file_path)
    raw = list(adapter.discover(target("silver compass")))
```

Git commit graph order and author timestamps are both retained; neither is silently substituted for the other. The lineage engine continues to interpret normalized evidence by its declared event-time semantics.

## Amendment C — CLI path classification

Task 8 must accept:

```text
roots trace TARGET PATH...
roots trace TARGET --git-file REPO:RELATIVE_PATH
```

A Git repository directory supplied as an ordinary `PATH` is not recursively interpreted as commit history. Git history requires explicit `--git-file`, preventing surprising or expensive history traversal.
